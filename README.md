# 🕵️‍♂️ Detective Sort: แฟ้มคดีปริศนาอัลกอริทึม

เกมการศึกษาบนเว็บที่นำขั้นตอนวิธีการจัดเรียงข้อมูล (**Sorting Algorithm**) มาเปลี่ยนเป็นกลไกการสืบสวนสอบสวนคดีอาชญากรรม ผู้เล่นจะรับบทเป็นนักสืบที่ต้องกู้คืนกระดานแฟ้มคดีที่คนร้ายสลับตำแหน่งไว้ โดยใช้กฎของ **Bubble Sort** และ **Selection Sort** เป็นกติกาในการคลี่คลายคดี

## 🎯 แนวคิดของเกม (Core Concept)

ในเกมนี้ **Sorting Algorithm ไม่ใช่แค่ฟังก์ชันเบื้องหลัง แต่เป็นแกนและกติกาหลักของการเล่นเกม (Core Mechanic)**:
* ผู้เล่นไม่สามารถสลับการ์ดได้ตามใจชอบ แต่ต้องปฏิบัติตามข้อจำกัดของอัลกอริทึมที่เลือก
* ผู้เล่นจะได้เรียนรู้และมองเห็นภาพ (Visualize) การทำงานของ Pointer, การเปรียบเทียบ (Compare) และการสลับข้อมูล (Swap) แบบ Step-by-Step

## 📜 กติกาของเกม (Game Rules)

ตัวเกมแบ่งออกเป็น 2 คดี เพื่อแสดงการทำงานของ 2 อัลกอริทึมที่แตกต่างกัน:

### 📁 คดีที่ 1: แกะรอยไทม์ไลน์ภาพถ่าย (Bubble Sort)
* **เป้าหมาย:** เรียงลำดับเวลาเกิดเหตุ (Timestamp) จากเช้าไปเย็น (อดีต - ปัจจุบัน)
* **กติกา:** 
  * ผู้เล่นสามารถคลิกเลือกเพื่อตรวจสอบและสลับ (Swap) การ์ดได้ **เฉพาะคู่ที่อยู่ติดกันเท่านั้น (Adjacent Items)**
  * ในแต่ละรอบ ข้อมูลเวลาที่เกิดทีหลังสุด (ค่ามากที่สุด) จะค่อย ๆ ลอยขึ้นไปอยู่ท้ายแถวเหมือนฟองสบู่

### 📁 คดีที่ 2: คัดกรองผู้ต้องสงสัย (Selection Sort)
* **เป้าหมาย:** เรียงลำดับแฟ้มผู้ต้องสงสัยตามระดับความน่าสงสัย (Suspicion Level) จากน้อยไปมาก
* **กติกา:**
  * กระดานจะแบ่งออกเป็น 2 ฝั่ง คือ **"ส่วนที่จัดเรียงแล้ว (Sorted)"** และ **"ส่วนที่ยังไม่ตรวจสอบ (Unsorted)"**
  * ในแต่ละรอบ ผู้เล่นต้องค้นหาผู้ต้องสงสัยที่มีค่าน้อยที่สุดในส่วน Unsorted แล้วนำมาสลับ (Swap) กับตำแหน่งหัวแถวของส่วนนั้น

### 🏆 เงื่อนไขผลแพ้-ชนะ (Win / Loss Condition)
* **ชนะ (Case Closed):** จัดเรียงหลักฐานถูกต้องครบทุกตำแหน่ง ระบบจะสรุปจำนวนการเปรียบเทียบ (Comparisons) และจำนวนการสลับ (Swaps)
* **แพ้ (Cold Case):** หากพยายามทำการสลับที่ผิดกฎของอัลกอริทึม (เช่น สลับข้ามช่องใน Bubble Sort หรือเลือกผิดตัวใน Selection Sort) ครบ 3 ครั้ง พลังชีวิตจะหมดลง

## 💻 Sorting Algorithm อยู่ตรงไหนและทำงานอย่างไรในโค้ด?

โค้ดทั้งหมดถูกพัฒนาในรูปแบบ **Single-File HTML** (รวม HTML, CSS และ JavaScript ในไฟล์เดียว) เพื่อความสะดวกในการเปิดและโฮสต์บนเว็บ

### 1. ฟังก์ชัน Bubble Sort (`bubbleSortAlgorithm`)
* **ตำแหน่งในโค้ด:** อยู่ในฟังก์ชัน `runBubbleStep()` และแท็บ `สมุดโค้ดอัลกอริทึม`
* **การทำงาน:**
  * **Outer Loop (`i`):** ควบคุมรอบการกวาดข้อมูลทั้งหมด $N - 1$ รอบ
  * **Inner Loop (`j`):** เปรียบเทียบข้อมูลคู่ติดกัน `arr[j]` กับ `arr[j + 1]` หากตัวหน้ามากกว่าตัวหลังจะเกิดการ Swap เพื่อดันค่าสูงสุดไปไว้ตำแหน่งท้ายสุดของรอบนั้น

### 2. ฟังก์ชัน Selection Sort (`selectionSortAlgorithm`)
* **ตำแหน่งในโค้ด:** อยู่ในฟังก์ชัน `runSelectionStep()` และแท็บ `สมุดโค้ดอัลกอริทึม`
* **การทำงาน:**
  * **Outer Loop (`i`):** ขยับขอบเขตของส่วน Unsorted จากหน้าไปหลัง
  * **Inner Loop (`j`):** สแกนหาตำแหน่งที่มีค่าน้อยที่สุด (`minIndex`) ในส่วนที่เหลือ
  * **Swap:** นำตำแหน่ง `minIndex` มาสลับกับตำแหน่งเริ่มต้น `i` เพียงครั้งเดียวต่อหนึ่งรอบ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5:** โครงสร้างหน้าเว็บและ Semantic Tags
* **Tailwind CSS (via CDN):** การจัดสไตล์และออกแบบธีมนักสืบย้อนยุค (Noir Detective Board)
* **Vanilla JavaScript (ES6+):** ควบคุม State, การคำนวณอัลกอริทึม และ DOM Manipulation
* **Web Audio API:** สังเคราะห์เสียงประกอบ (Sound Effects) ในตัว โดยไม่ต้องพึ่งพาไฟล์เสียงภายนอก
